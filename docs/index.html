    開始前，你可能想知道

    常見問題

    怎麼安裝？需要什麼系統？

    需要 Windows x64 與 Microsoft WebView2 Runtime。下載安裝版依指示安裝，或完整解壓免安裝版後執行 Skilnex.exe 即可。

    同步會覆蓋或刪除我的檔案嗎？

    同步會以來源的完整資料夾取代目標，可能移除目標獨有的檔案，所以每次都先預覽差異。目標有修改時需另外同意取代；預覽後有變動會先停止。取代前會保存副本，可從操作日誌預覽還原；若檔案又被修改，還原也會要求重新檢查。

    支援哪些 Agent？

    內建 Codex、Claude Code、OpenCode、Pi、Hermes、OpenClaw 的技能目錄偵測，也可加入自訂目錄與 Git 專案。靜態檢查不會執行技能；實際載入仍取決於各 Agent 的設定與支援情況。

    需要一直連網？技能會被上傳嗎？

    盤點、閱讀、整理與同步在本機完成，不會將技能內容上傳。下載、GitHub 匯入與版本更新則需要網路。

    跟手動複製資料夾有什麼不同？

    你能先看逐檔差異、確認既有修改，並保留取代前的副本。搜尋、收藏與筆記，也讓下次使用更順手。
