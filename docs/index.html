    05 / GOOD TO KNOW

    了解能力，
    也了解邊界。

    Skilnex 會幫我執行技能或派遣 Agent 嗎？

    不會。它管理本機技能檔案與附帶內容，提供閱讀、整理、靜態檢查與人工確認的單向同步。它不是 AI 聊天介面，也不是多 Agent 任務編排平台。

    同步會自動覆蓋我的修改嗎？

    不會直接覆蓋未確認的修改。目標有衝突時需要另外同意取代；來源或目標在預覽後變動，會阻擋執行。取代前保存副本，還原時也會重新檢查現況。不背景自動同步，來源消失也不自動刪除目標。

    通過檢查，代表技能安全而且一定能執行嗎？

    不是。manifest、檔案結構、連結與命令提示都是靜態檢查，不能保證安全或跨 Agent 相容。實際載入仍受 Agent 版本、信任、權限及既有對話等條件影響。

    MCP 與外部技能的管理範圍是什麼？

    MCP 僅唯讀盤點已支援格式的既有設定，不啟動服務、不寫設定、不聲稱連線成功。外部技能仍由原 Agent、安裝工具或你更新；Skilnex 不提供外部副本更新檢查或原地更新。套件、外掛、內建及連結目錄不作為同步覆寫目標。

    支援哪些系統？需要一直連網嗎？

    目前提供 Windows x64，並需要 WebView2 Runtime。本機盤點、閱讀與同步處理本機檔案；GitHub 匯入、下載、版本檢查與應用更新可能需要網路。不宣稱 macOS、Linux、遠端／WSL、私人技能來源或第三方 MCP extension 支援。

    這是開源軟體嗎？企業使用有什麼承諾？

    桌面原始碼目前未公開。公開下載不等於開源或已授予商用授權，本頁不新增授權條款、企業合規或 SLA 承諾。若公司政策阻擋安裝，請依管理政策處理，不建議關閉安全保護。
