NATIVE / VERIFIED FILE OPERATIONS

預覽過，不代表可以直接覆寫。

57 秒真實桌面操作：預覽後改動目標，讓過期檢查實際擋下一次同步。

真實桌面操作錄影：預覽差異、衝突阻擋、確認後同步。

靜態截圖與文字步驟（無法播放時也能閱讀）
  1. 盤點兩個自訂測試目錄，選擇 code-review 來源與 Demo Target。
  2. 真實差異視窗並列目標現有內容與來源，顯示兩個差異檔案。
  3. 測試腳本在畫面外修改目標後，按下確認。native backend 回報「Destination changed after preview; scan and review again」；檔案雜湊證明目標未被覆寫、來源未變。
  4. 重新預覽，外部修改仍可見。再次檢查衝突並明確勾選同意取代後，才完成同步。
  5. 在目標閱讀器與操作日誌對照結果。SHA-256 驗證來源不變、目標等於來源，且備份保留被取代前的目標內容。

    04 / GOOD TO KNOW

    常見問題

    怎麼安裝？需要什麼系統？

    需要 Windows x64 與 Microsoft WebView2 Runtime。下載安裝版 *_x64-setup.exe 依指示安裝；或下載 *-portable.zip 完整解壓後直接執行 Skilnex.exe，免安裝、可隨身攜帶。

    同步會不會覆蓋或刪掉我的檔案？

    不會直接覆蓋。每次同步先預覽完整檔案差異；目標有修改時需要另外勾選同意，預覽後檔案有變動會自動阻擋。取代前會保存目標副本，可從操作日誌還原。

    支援哪些 Agent？

    內建 Codex、Claude Code、OpenCode、Pi、Hermes、OpenClaw 的技能目錄偵測，也可以加入自訂技能目錄與 Git 專案。

    需要一直連網嗎？

    不用。盤點、閱讀、檢查與同步都在本機完成；只有下載安裝、GitHub 匯入與版本更新需要網路。

    我的技能會被上傳嗎？

    不會。所有內容都留在你的電腦上，Skilnex 不上傳任何資料。

    跟手動複製資料夾有什麼不同？

    Skilnex 先列出每個檔案的差異再讓你確認，附帶衝突防護、取代前備份、一鍵還原，以及收藏、筆記與全文搜尋。
